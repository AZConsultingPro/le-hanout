# Le Hanout

Atelier de projet pédagogique CAP EPC — LP Daniel-Balavoine.

Cinq services, treize élèves, quatre séances. Parcours guidés, lexique, vingt Google Forms, sauvegarde locale exportable et comptes rendus.

## Utilisation
Ouvrir le site GitHub Pages, choisir son prénom et son parcours. En fin de séance, télécharger la progression JSON et le compte rendu, puis déposer les deux dans le dossier Drive privé du service. Sur un autre poste, importer la sauvegarde.

Les pourcentages sont des déclarations d’avancement, pas des notes. Les scores sont consultables dans le tableau Forms privé. Les enseignants consignent séparément la validation des productions. Le dépôt Drive des exports est manuel et guidé.

## Confidentialité
Le site public ne reçoit ni mots de passe, ni réponses de quiz, ni productions élèves. La consultation enseignants lit les sauvegardes choisies sur leur appareil. Les dossiers Drive et le tableau de réponses conservent leurs restrictions d’accès.
